About Project

Student Mark Predictor — AI-powered academic analytics platform.

Project Overview

Student Mark Predictor is a machine learning web application that predicts expected academic performance based on daily study duration. The system combines a Flask backend, trained machine learning model, NumPy numerical processing, Pandas data management, and an interactive frontend dashboard.
